How to get your audit

Use a computer with Chrome. It takes about a minute.

  1. Run your auditOpen MyDegreePath, then choose Run Program and View Audit. Undeclared? Choose Select a Different Program to run a What-If audit.
  2. Save the pageRight-click a blank area, choose Save as, then pick “Webpage, HTML Only”.
  3. Upload it hereYou’ll see your classes for every semester through graduation.
